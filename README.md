# Developer Portfolio

A minimalist developer portfolio built with React, Vite and Tailwind CSS.

## Requirements

- Node.js 18+
- npm

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown by Vite.

## Build

```bash
npm run build
npm run preview
```

## Customize

Edit `src/main.jsx`:

- Name and profile text
- GitHub / LinkedIn / email links
- Skills
- Projects
- Project descriptions
- Project links

Replace the placeholder images in `public/images/` with your real screenshots.

## GitHub Pages

The project uses:

```js
base: './'
```

in `vite.config.js`, so it can be deployed as a static Vite site.
